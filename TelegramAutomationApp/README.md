# ⚡ Telegram Multi-Account Automation Platform

منصة متكاملة لأتمتة حسابات تيليجرام المتعددة (إرسال رسائل مباشرة مع الصور + إضافة الأعضاء للمجموعات + استيراد ملفات إكسل و CSV + نظام حماية ذكي ضد الحظر).

---

## 📁 هيكلية ملفات المشروع (Directory Structure)

```text
d:\Telegram Multi-Account Automation\
│
├── index.html                  # ملف الواجهة الرئيسي للفتح المباشر في المتصفح
├── Start_Server.bat            # ملف التشغيل السريع بنقرة واحدة (One-Click Launcher)
├── README.md                   # دليل الاستخدام والتشغيل
│
└── TelegramAutomationApp\
    └── Backend\                # كود الخلفية البرمجية (.NET 8 ASP.NET Core API)
        ├── Controllers\        # وحدات التحكم في الحسابات والحملات ورفع الملفات
        ├── Database\           # قاعدة بيانات SQLite (app_data.db)
        ├── Hubs\               # SignalR Hub لنقل السجلات والبيانات لحظياً
        ├── Models\             # نماذج البيانات (Accounts, Campaigns, Targets)
        ├── Services\           # محرك الجلسات WTelegramClient والحماية ضد الحظر
        ├── Sessions\           # مجلد تخزين جلسات تيليجرام (.session)
        └── wwwroot\            # ملفات الواجهة الأمامية (HTML, CSS, JS, Uploads)
```

---

## 🚀 طريقة التشغيل السريع (How to Run)

1. **طريقة التشغيل بنقرة واحدة**:
   - اضغط مرتين على ملف **`Start_Server.bat`**.
   - سيقوم السكربت بتشغيل سيرفر الـ Backend وفتح الواجهة فوراً على المتصفح عبر الرابط: `http://localhost:5000`.

2. **طريقة فتح الواجهة مباشرة**:
   - يمكنك فتح ملف **`index.html`** مباشرة في أي متصفح أثناء عمل السيرفر.

## 💡 المميزات والوظائف الأساسية

1. **إدارة حسابات تيليجرام المتعددة**:
   - إضافة حسابات باستخدام (`Phone Number` + `API ID` + `API Hash` من https://my.telegram.org).
   - التحقق برمز OTP مع دعم التحقق بخطوتين (2FA Password).
   - منع تعارض الجلسات تلقائياً وحفظها بأمان داخل مجلد `Sessions/`.

2. **استيراد ملفات Excel و CSV**:
   - سحب وإفلات (Drag & Drop) لأي ملف `.xlsx` أو `.csv` يحتوي على بيانات العملاء.
   - استخراج أسماء المستخدمين تلقائياً وفلترة الأرقام والقيم غير الصالحة.

3. **إرسال الرسائل المباشرة مع الصور (Direct Messaging)**:
   - دعم إرفاق الصور والوسائط.
   - محرر تفاعلي مع معاينة حية لشكل المحادثة على تيليجرام (Telegram Live Chat Preview).
   - دعم تخصيص النصوص باستخدام المتغير `{username}`.

4. **إضافة الأعضاء للمجموعات (Group Member Adder)**:
   - إضافة الأعضاء للمجموعات العامة أو الخاصة مع توزيع الحمل بالتساوي بين الحسابات المتاحة.

5. **نظام الحماية من الحظر (Anti-Ban Protection)**:
   - تأخير عشوائي بشري ذكي (8 - 20 ثانية) مع استراحات دورية لمنع حظر الحسابات.
   - معالجة ذكية لاستثناءات `FLOOD_WAIT` ووضع الحساب في التبريد المؤقت تلقائياً.

6. **مراقبة حية وشاشة تفاعلية (Live Monitor & Terminal)**:
   - تحديث العدادات (Total, Processed, Success, Failed) لحظياً.
   - جدول يوضح حالة كل عميل تم الإرسال له مع اسم الحساب والتوقيت.
